# Security Policy

## Supported Versions

Peekr is in active early development. Security fixes land on the latest release
and on `main`.

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's [private vulnerability reporting][advisory] to disclose
the issue confidentially. If that is unavailable, contact the maintainer
directly.

When reporting, please include:

- A description of the vulnerability and its impact
- Steps to reproduce (and the macOS / Xcode version you used)
- Whether you reproduced it with `make run` (`.app` bundle) or `make dev`

We aim to acknowledge reports within a few days and will keep you updated on the
fix. Thank you for helping keep Peekr and its users safe.

[advisory]: https://github.com/KiWi233333/Peekr/security/advisories/new
