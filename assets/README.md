# Assets

Marketing/doc images referenced by the project READMEs. Drop the following files
here and they'll show up automatically:

| File | Used in | Suggested size |
|------|---------|----------------|
| `icon.png` | README header logo | 256×256 (square, transparent) |
| `hero.png` | README hero banner | ~1640×1024 (2× for retina) |
| `screenshot-panel.png` | Screenshots section | slide-over panel in action |
| `screenshot-prefs.png` | Screenshots section | Preferences window |

Tips:
- Export at **2×** so they stay crisp on retina displays; the READMEs constrain
  the display width.
- Prefer PNG for UI screenshots; an animated GIF/MP4 of the peek motion makes a
  great hero if you have one (reference it from the READMEs).
- Keep file sizes reasonable (compress with e.g. `pngquant` / ImageOptim).
